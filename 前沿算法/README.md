本目录是现有数学建模项目中的方法研究区。外部论文和代码提供候选证据，不构成新增项目或直接采用复杂模型的理由。

## 按需阅读

- [MFTabPFN 多保真回归](MFTabPFN_多保真回归.md)：不同成本与精度的数据怎样支持高保真目标预测。
- [RankReg 排序与回归](RankReg_排序与回归.md)：数值误差与候选筛选目标怎样同时评价。
- [近期论文追踪](近期论文追踪.md)：Nature 主刊概率偏差校正，以及 Science Advances 神经 ODE／符号回归候选。
- [版本与核验清单](catalog.json)：固定代码版本、许可证标签、文件指纹与未执行项。

## 证据和使用边界

检索优先近期发表的原始论文，记录发表日期、DOI、精确期刊身份和阅读深度。Nature Portfolio、Science Advances 与 Nature、Science 主刊分别标明；中科院分区按官方年度、大类/小类核验，JCR Q1 和影响因子不能替代。未核验分区保留待核验状态。

固定代码版本和静态阅读不等于复现。候选条目在完成公式、边界、最小运行和任务匹配训练外比较前，不提升为主模型推荐。外部权重、数据和依赖分别核对许可证；本包不分发其原始内容。

方法库使用本目录设计基线、消融和验证；审查库使用它核查必要性、解释与证据边界。正式使用仍执行各包原有阶段门禁；不默认加载整个目录。没有相应结果时不编造性能图、误差条或科学发现。

公开包不含维护者的原始证据快照。条目中的公开来源可供独立核对；没有完成原文和结果复现的部分保持候选状态。
