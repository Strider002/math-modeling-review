## Nature 主刊：概率偏差校正 PBC

[Advancing subseasonal forecasting with machine learning](https://www.nature.com/articles/s41586-026-11126-x)，2026-10-14，DOI 10.1038/s41586-026-11126-x。原页面的 Introduction、Probabilistic bias correction 与 Code availability 已阅读；`source:FRONTIER-PBC-NATURE-2026`。

论文以现有集合预报为输入，学习概率层面的系统误差校正，输出校正后的概率预报。值得备赛研究的点是：当已有预测存在可学习的系统误差时，先考虑后处理，而非重新建立更大的预测系统。此处不转载性能倍数，也不把天气任务的效果当作其他任务保证。

最低验证计划：同一输入和时间划分比较原始预测、简单偏差校正与 PBC；报告概率评分、校准及分预测期表现，极端事件另列。训练、分位阈值和气候基线只能使用当时可用的信息。缺少历史集合预测、样本不足或分布漂移时暂不采用。

Code availability 明确指向 [mouatadid/pbc](https://github.com/mouatadid/pbc) 与 [Zenodo 归档](https://doi.org/10.5281/zenodo.22238796)。2026-10-29已补固定版本、许可和部分入口静态审阅，详见下节；最小运行、数据审计及性能仍未复现，中科院分区另待核验。

### 2026-10-29：固定代码与最小审查契约

固定 [mouatadid/pbc](https://github.com/mouatadid/pbc/tree/d59e18f720bac712e18563bd469d4679c120f9e5) 的 commit 为 `d59e18f720bac712e18563bd469d4679c120f9e5`。GitHub 元数据和根 LICENSE 为 MIT；README 回链至同一 Nature DOI，与此前论文 Code availability 的仓库链接相互对应。静态阅读范围为 README、LICENSE、环境清单、climatology、projector 及 pbc_ecmwf 批入口；所读文件指纹已保存。仓库、数据和依赖授权分别核对。`source:FRONTIER-PBC-CODE-2026`。

**复现障碍**：固定 README 的组合模型示例写 src/models/abc_ecmwf/bulk_batch_predict.py，但递归目录中无该路径；实际存在 src/models/pbc_ecmwf/bulk_batch_predict.py。不能照抄原命令后声称运行通过，也不能仅凭名称替换保证复现。README 声明测试环境为 Rocky Linux/Python 3.13.3，环境清单含 Linux 构建与个人 prefix，不能当作已验证的 Windows 安装方案。ERA5 与 ECMWF 下载另需对应机构账户/条款和凭据；本次未读取凭据、未下载大数据、未安装或运行外部入口。

**静态实现边界**：projector 脚本先裁切到 [0,1]，再对不单调的四个累积概率做保序回归；缺少四份输入文件时跳过相应日期。它还创建派生模型目录并写 NetCDF，不能按只读脚本运行。已读范围不构成全仓安全审计。

| 审查问题 | 必须区分的结果 | 本次状态 |
|---|---|---|
| 演示是否验证 PBC | README 首个 demo 是 climatology，常数累积概率基线，不是 PBC 性能复现 | 已静态核对 |
| 概率是否合法 | 有界、阈值方向正确、累积值不降；分箱概率非负且总和为1 | 仅下列原创算例回核 |
| 概率是否可靠 | 已报概率与后续实际频率是否相符，是否改善预先选定评分 | 未检验；合法 CDF 不保证校准 |
| 是否值得增加模型 | 同一历史输入与滚动划分下，比较原预测、简单校正、PBC及组件消融 | 尚无本地比较 |
| 有没有暗中删失败样本 | 对齐每个候选共同可评价的日期/格点，同时报告缺失、跳过和失败范围 | 待实际数据审计 |

原创无量纲手算例：四个**累积概率**为 (-0.1,0.6,0.4,1.1)，裁切后为 (0,0.6,0.4,1)，中间两个值仍逆序。将这对逆序值合并为均值0.5，得 (0,0.5,0.5,1)；作相邻差并补两端，五箱概率为 (0,0.5,0,0.5,0)。使用标准库 Fraction 回核6个算术/不变量检查通过。此例不是上游代码运行、完整保序算法测试、统计校准或天气预测效果证据；缺失值不能用这个例子里的0代替。

**用于方法库的验证契约**：先冻结目标变量、发行日、预测期、观测可得日、阈值定义及气候基准时期；所有阈值、调参和校正只用当时可见的历史。固定同一原始预报与评价日期，先比简单后处理，再考察 PBC。记录概率评分、校准、分预测期表现、运行成本和失败范围；极端事件另审，不靠平均改善代替尾部证据。实际试验前仍需完成数据与选模门禁。

**用于审查库的解释和图表契约**：至少核对发行日—观测日时间线、原始/简单校正/PBC的同条件评分，以及校准图所需的实际概率与验证事件。没有预测结果时只列需要的字段，不画虚构改善曲线。主张若只是概率合法，不能以平滑CDF图代替校准或预测验证；改进概率评分也不等于已改善下游决策。

英文计划表述：

> We will test whether a correction layer improves the existing forecasts under a rolling evaluation. All methods will use the same information and target dates. Valid probability distributions are a prerequisite; they do not by themselves demonstrate calibration or predictive skill.

这段使用未来时，因为尚无本地 PBC 实验。方法仍为候选，未新增性能或视觉验收。
