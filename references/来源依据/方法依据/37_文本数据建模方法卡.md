# 文本数据建模方法卡

## 1. 首先定义样本单位

明确一行是句子、文档、用户、主题还是时间窗。标签若来自未来、人工总结或同一作者的重复文本，随机按行切分会造成泄漏；优先按作者、来源、事件或时间分组。

## 2. 最小可审计路线

1. 保存原文、编码、语言和去重指纹，不覆盖原始语料。
2. 先划分训练/验证/测试，再仅在训练集拟合词表、IDF、主题数和阈值。
3. 建立多数类、关键词规则及 word/character n-gram + 线性模型基线。
4. 深度表示或大模型必须与同划分、同指标、同预算基线比较。
5. 报告宏/微指标、类别支持数、混淆矩阵和典型错误。

词袋把文档表示为词项计数矩阵，忽略远距离顺序；TF–IDF 的具体公式与平滑方式依软件实现而异，必须锁定版本和参数。证据：`source:SKLEARN-TEXT-CURRENT`。

## 3. 中文与多语言边界

- 中文分词、字符 n-gram 和子词方案分别比较；词典不能由测试集扩充。
- 停用词不是固定真理；否定词、程度词或领域词可能直接决定标签。
- 翻译或大模型生成扩增要记录模型、提示、日期和人工复核，且不能跨测试边界。

## 4. 验证与局限

除随机划分外，至少做一种更接近部署的作者外、来源外或时间外验证。检查近重复文本、模板页眉、文件名和元数据泄漏。结论限制在采样语域、时期和标签规则；主题或嵌入相似不等于因果或事实正确。

## 5. 复现清单

保存语料清单与哈希、许可/隐私状态、去重规则、切分键、分词器、词表、IDF、模型参数、随机种子、错误样本 ID 和指标脚本。
