# 图像数据建模方法卡

## 1. 样本与切分

先确定预测单位是像素、目标、图像、个体还是场景。来自同一患者、零件、视频、地点或增强母图的样本必须放在同一侧；近重复图像用感知哈希或元数据检查。

## 2. 最小模型链

1. 保留原图与 EXIF/采集台账，统一方向、颜色空间和尺度。
2. 先按实体/场景划分，再从训练集估计归一化、阈值和增强策略。
3. 建立灰度/颜色阈值、形态学、轮廓或纹理等可解释基线。
4. 再比较迁移学习或检测/分割模型，固定划分与计算预算。
5. 任务匹配指标：分类看类别指标与校准；检测看 IoU/AP；分割看 Dice/IoU 和边界误差。

OpenCV 官方图像处理模块包含颜色转换、滤波、阈值、形态学、轮廓和几何变换；这些算子参数依成像条件而变，不能把一幅图上调出的阈值当通用常数。证据：`source:OPENCV-IMGPROC-4.13`。

## 3. 验证与压力测试

- 按设备、批次、主体和时间外验证。
- 检查旋转、尺度、压缩、照明、遮挡和背景变化。
- 展示失败样本、类别支持数和置信区间，不只展示最佳图。
- 分割/检测标注需要双人一致性或抽样复核；标注不确定区单独报告。

## 4. 常见错误

- 增强后再切分导致母图泄漏。
- resize 扭曲物理尺度但仍解释面积/长度。
- 用准确率掩盖稀有类失败。
- 热力图被当作因果解释或定位真值。
- 将第三方预训练权重、许可或数据来源省略。

## 5. 复现清单

保存图像清单与哈希、实体分组键、标注版本、颜色/尺度处理、增强随机种子、权重来源与许可证、阈值、评估脚本、失败样本 ID 和导出模型版本。
