# 信号处理与频谱建模方法卡

## 1. 数据契约

记录采样频率、时间戳单位、通道、传感器量程、校准、缺测、饱和和抗混叠条件。重采样、滤波、去趋势和归一化均只能在训练边界内拟合参数。

## 2. 路线选择

- 稳态周期：周期图或 Welch 功率谱密度。
- 非平稳瞬态：短时傅里叶或小波，并报告时频分辨率取舍。
- 多通道：互谱、相干性或状态空间模型，先检查同步与共同干扰。
- 预测/分类：时域统计、频带能量和物理特征基线，再比较学习模型。

Welch 方法将序列分段、加窗、计算修改周期图并平均；分段长度、重叠、窗和缩放改变方差、频率分辨率及单位。证据：`source:SCIPY-WELCH-CURRENT`。

## 3. 验证门禁

1. 用已知频率和幅值的合成正弦做手算/解析小例。
2. 检查频率轴、单/双边谱、PSD 与 spectrum 的单位。
3. 改变窗、段长、重叠和去趋势，报告主峰与能量的稳定性。
4. 按设备、受试者、批次或完整时间段切分，禁止把相邻窗口随机散入两侧。
5. 与时域基线及保留工况比较，报告置信区间或重复实验波动。

## 4. 常见错误

- 未给采样频率却解释绝对频率。
- 把零填充当作增加真实分辨率。
- 滤波后不报告相位、边界和延迟。
- 同一长信号切窗后随机交叉验证。
- 只挑最漂亮频谱，不做参数敏感性。

## 5. 复现清单

保存原始采样清单、通道单位、窗口索引、预处理顺序、滤波器系数、窗函数、段长、重叠、缩放、随机种子、软件版本和输出哈希。
