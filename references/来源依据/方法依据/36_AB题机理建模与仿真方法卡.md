# A/B 题机理建模与仿真方法卡

## 1. 适用问题与输出

适用于守恒、运动、传热传质、反应、控制或离散事件机制主导的问题。输出应是可解释的状态轨迹、参数区间、约束下方案或情景比较，不是只追求拟合分数。

## 2. 最小模型链

1. 画系统边界，区分状态量、控制量、外生量和观测量。
2. 由守恒、几何或行为规则写方程，并逐项检查量纲和符号。
3. 先建立可手算或有解析解的简化基线，再增加必要机制。
4. 把状态方程与观测方程分开；参数拟合只使用训练段或校准实验。
5. 用未参与校准的时段、工况或实验做训练外验证。
6. 对步长、网格、初值、参数和边界条件做敏感性与收敛检查。

## 3. 数值实现门禁

连续初值问题写为

\[
\dot x=f(t,x,u,\theta),\qquad x(t_0)=x_0.
\]

显式 Runge–Kutta 通常用于非刚性问题，Radau/BDF 等隐式方法适用于刚性问题。事件时刻应使用根事件检测，并检查一步内多次过零可能被漏检的边界。软件选项是版本化契约，不能替代理论条件。证据：`source:SCIPY-SOLVE-IVP-CURRENT`。

## 4. 基线、验证与不确定性

- 基线：静态平衡、线性化、无反馈或单主体版本。
- 验证：解析小例、守恒量、非负性、极限情形、步长/网格加密和独立算法交叉。
- 校准：报告参数边界、可识别性、多初值和区间，不只给一个最优点。
- 决策：将参数和外生情景不确定性传播到目标与约束；随机仿真报告重复次数和区间。

## 5. 常见失分

- 机制项越多越好，导致参数不可识别。
- 用同一轨迹校准又验证。
- 把数值求解器成功状态当作物理正确或全局最优。
- 不检查单位、边界、守恒、步长或网格。
- 只给漂亮动画或单条曲线，没有误差和反事实基线。
