# 新增图表指南来源

新图表模块是按任务与主张组织的原创规划，不是赛事官方图种清单。数学方法的详细证据见 [来源索引](来源索引.md) 与本包方法依据。

## 软件与方法定义

- [scikit-learn：Probability calibration](https://scikit-learn.org/stable/modules/calibration.html)：可靠性图、概率输出与校准边界。
- [scikit-learn：Precision–Recall](https://scikit-learn.org/stable/auto_examples/model_selection/plot_precision_recall.html)：类别不平衡下的 PR 展示及 AP 定义。
- [Hyndman 与 Athanasopoulos：预测误差评估](https://otexts.com/fpp3/accuracy.html)：训练外预测、误差和指标适用范围。
- [pymoo：Visualization](https://pymoo.org/visualization/index.html) 与 [Parallel Coordinates](https://pymoo.org/visualization/pcp.html)：多目标结果的散点与平行坐标实现类型。

上述网页于 2026-09-20 查阅；软件页面随版本变化，具体 API 使用前须重查。本包不承诺任何算法因采用这些图表而更准确。

## 科学表达与技能参考

图表规划参考了 Scientific Agent Skills 中 scientific-visualization 的真实性、区间标注和最终尺寸审查原则；未打包其脚本、样式、图片或模板。

Kassis, T., Agarwal, V., He, Y., Patel, D., & Brueckner, A. M. (2026). *Scientific Agent Skills: A Library of Procedural Knowledge for Research Agents*. [arXiv:2609.00065](https://doi.org/10.48550/arXiv.2609.00065)。作者、年份与当前记录于 2026-09-20 核对。该引用说明设计来源，不证明本包经过任务级效果评测。
