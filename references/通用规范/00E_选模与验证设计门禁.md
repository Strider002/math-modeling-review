# 选模与验证设计门禁

本文件在筛选候选模型之前加载。它把验证方案前置到建模之前，防止先看结果再选择划分、指标或基线；
正式残差诊断、敏感性、压力测试和不确定性传播仍在产生结果后按
[11_验证敏感性与不确定性.md](../模型审查/11_验证敏感性与不确定性.md) 执行。

## 1. 先定义目标或估计对象

在列出模型名称前，明确：

- 决策问题和最终用途；
- 要估计、预测、排序、解释或优化的对象；需要因果结论时明确 estimand、处理、结局和目标总体；
- 输出形式、时间或空间范围及所需粒度；
- 评价标准和错误代价；
- 可接受的解释、计算、延迟和复现要求；
- 哪些问题因数据或识别条件不足而不作答。

只写“提高准确率”或“建立最优模型”不足以进入选模。

## 2. 响应支持集与观测机制

确认响应变量属于哪类支持集及其边界：

- 无界或有界连续量；
- 仅正值、比例、组成或半连续量；
- 二元、多类别或有序类别；
- 计数、发生率或带暴露量的事件数；
- 时间到事件，以及是否存在删失、截断或竞争风险；
- 曲线、图、空间场、多个关联响应或其他结构化输出。

同时检查零值、上下界、离散化、测量误差、选择机制和标签定义。候选模型的输出范围、分布和损失
必须与响应及观测机制相容。

## 3. 依赖结构

逐项判断是否存在：

- 时间顺序、季节、滞后、结构突变或滚动更新；
- 空间邻接、距离、区域层级或空间泄漏；
- 同一对象重复观测、面板、批次、中心、家庭或其他分组；
- 多层嵌套、交叉随机效应或相关响应；
- 网络连接、干扰、选择偏差或内生性。

若存在依赖，候选模型、标准误和验证划分都必须保留该结构；把相关观测当作独立样本属于硬否决。

## 4. 外推与部署目标

- 明确是在现有样本内描述、预测同分布新样本，还是外推到未来、其他地区、其他群体或干预情景。
- 说明部署时输入的可得时间、延迟、更新频率和允许使用的历史窗口。
- 指定目标总体、预测窗口、空间范围、组别或决策场景。
- 识别训练与目标环境在口径、变量范围、机制和缺失上的潜在差异。
- 结构外推需要机理、形状约束、因果识别或外部证据；不能只凭样本内拟合曲线延长。

## 5. 验证设计必须前置

### 验证单位与划分

- `split unit` 应对应真正独立的新对象：时间块、空间块、个体、组、中心或完整事件链，而非默认单行。
- 划分方式必须匹配最终部署：随机留出、分组留出、滚动起点、时间回测、空间阻断或外部验证。
- 预先说明训练、调参验证和最终测试的职责；最终测试在候选、特征和超参数冻结前保持隔离。
- 样本不足以独立留出时，说明替代设计及其限制，不把交叉验证结果冒充外部验证。

### 指标与比较单位

- 指标由目标、响应支持集和错误代价决定，并在看模型结果前确定主指标与辅助指标。
- 明确按行、对象、组、时间窗口、空间单元还是事件计算和聚合指标。
- 不能只报告一个平均指标；需要时预先规划分组、区间、校准或尾部风险检查。
- 所有候选在相同数据版本、外层划分、指标定义和评估单位下比较。

### 调参与信息边界

- 插补、缩放、编码、筛选、降维、重采样、模型选择和超参数搜索全部位于训练或内层验证中。
- 外层测试不得用于选择特征、模型、阈值、随机种子或停止轮数。
- 时间、空间、对象和组的关联信息不得跨越划分边界。
- 堆叠或集成的二层输入使用训练外基预测，不直接使用同一训练样本的拟合值。
- 若测试集已经影响决策，必须降级为验证集并另行确定最终评估边界。

## 6. 先建立简单基线

基线必须与目标和验证协议一致，例如现行策略、均值或中位数、上一期、季节性朴素法、简单线性或
逻辑模型、等权规则、简单可行解或解析近似。基线不是装饰；它用于判断新增模块是否带来稳定、
可解释且足以抵偿复杂度的改进。

若不存在自然基线，必须说明原因并构造最简单可行对照。

## 7. 筛选 2—5 个候选

通过目标、响应支持集、依赖结构、数据量、外推要求和资源约束，保留 2—5 个有明确角色的候选：

- 一个简单基线；
- 一个满足主要数据结构的主候选；
- 必要时加入处理关键缺陷的替代模型；
- 只有在样本、算力和验证预算足够时加入高复杂度模型。

每个候选必须写明：解决基线的哪个缺陷、关键假设、所需数据、输出是否满足约束、主要失败模式、
训练与调参成本，以及准备如何证伪。方法属性评分只能辅助初筛，不能替代硬门禁和训练外比较。

## 8. 硬否决信号

- 目标或 estimand 含糊，预测、解释与因果要求混在一起；
- 模型输出范围或分布与响应支持集、删失或选择机制不相容；
- 忽略已知时间、空间、分组、层级或重复测量依赖；
- 验证单位与部署单位不同，或同一对象的信息跨越训练和测试；
- 在查看外层测试结果后反复选择模型、特征、阈值或指标；
- 数据驱动预处理在划分前用全数据拟合；
- 没有简单基线，或不同候选使用不同划分和指标；
- 参数数量、模型自由度或搜索空间明显超出有效样本与验证能力，却没有收缩、先验或降复杂度方案；
- 需要因果或结构外推，却只有相关拟合和样本内性能；
- 候选无法提供题目要求的输出、约束或可执行决策。

出现任一信号时先修正目标、数据、划分或候选，不进入正式调参和结果比较。

## 9. 最小选择记录

选模完成后保存以下记录：

| 项目 | 必填内容 |
|---|---|
| 任务目标 | 用途、输出、estimand 或预测对象、目标总体 |
| 响应与观测 | 支持集、边界、删失/截断/选择或测量机制 |
| 依赖结构 | 时间、空间、对象、组、层级、网络及处理方式 |
| 外推/部署 | 目标环境、窗口、可得输入、更新频率和漂移风险 |
| 验证设计 | split unit、外层划分、内层调参、最终测试隔离 |
| 指标 | 主指标、辅助指标、计算与聚合单位、错误代价 |
| 简单基线 | 定义及选择理由 |
| 候选 2—5 个 | 角色、关键假设、解决的缺陷、成本和否决条件 |
| 泄漏检查 | 预处理、特征、调参、集成和测试信息边界 |
| 后续验证 | 残差、敏感性、压力测试、不确定性和外部验证计划 |
| 未决风险 | 无法核验项、影响范围和降级结论 |

## 10. 与后续验证衔接

本阶段只冻结验证协议和后续检查计划，不提前声称模型稳健或有效。获得训练外结果后，完整读取并执行
[11_验证敏感性与不确定性.md](../模型审查/11_验证敏感性与不确定性.md)：检查残差或误差结构、基线差异、参数和数据处理敏感性、合理极端
情景、区间或分布、不确定性传播、约束违反量及失效条件。若执行中修改候选、特征、指标或验证设计，
必须回到本门禁更新记录，并重新保护最终测试边界。
