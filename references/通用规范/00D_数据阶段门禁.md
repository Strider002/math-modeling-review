# 数据阶段门禁

本文件只在读取数据、建立数据字典、清洗、EDA、连接表、特征工程或准备训练数据时加载。
目标是在建模前固定数据身份、口径、依赖与可得性；它不替代具体题型的数据专题。

## 1. 数据身份与来源

- 保存原始文件或官方接口的名称、来源、许可或使用边界、获取时间、版本和修订状态。
- 对进入分析的原始文件记录 SHA-256；文件发生变化时视为新版本，不静默替换。
- 区分原始数据、外部补充数据、人工标注、模拟数据和处理后数据；不得混写来源。
- 网页、数据库或 API 数据记录查询条件、时间窗口、分页规则和必要的软件版本。
- 原始资料默认只读；清洗结果写入新文件，并保留从原始数据到分析数据的可追溯步骤。

## 2. 口径、单位与时间

逐列确认：

- 对象、总体和观测单位；
- 字段定义、编码与允许值；
- 数值单位、币种、价格基期或比例分母；
- 日期的含义、频率、时区、起止边界和是否为事件时点或统计期；
- 空间层级、坐标系或区域边界；
- 缺失、零、负值、上限值和特殊代码的业务含义。

单位换算、频率聚合、时间对齐和口径变更必须留下规则，不能只在结果中说明“已处理”。

## 3. 主键、重复与连接

- 明确候选主键及其粒度，检查主键缺失和重复。
- 区分完全重复、同一对象的合法重复观测和冲突记录，不默认保留第一条或删除全部重复。
- 每次连接前说明是一对一、一对多还是多对多，并核对连接键的数据类型、空值及时间有效区间。
- 每次连接后记录左表、右表和结果的行数，以及未匹配、重复扩张和字段冲突数量。
- 面板、层级和事件数据保留对象、组、时间及事件标识，不能因排序或聚合破坏依赖结构。

## 4. 缺失与异常

- 先统计缺失位置、比例、模式和与时间、组别、响应变量的关系，再选择处理方式。
- 区分可解释的结构性缺失、记录缺失和未知缺失机制；机制无法判断时明确不确定性。
- 插补方法、使用变量、拟合范围和随机性必须记录；需要训练外评估时只在训练部分拟合插补器。
- 异常值先核对单位、录入、设备、时间和业务事件，再判断是错误、罕见但真实的观测还是目标现象。
- 不得仅因数值极端或降低拟合效果而删除观测；删除、截尾、缩尾或稳健处理均记录规则和影响。
- 比较关键结论在保留、修正或不同异常处理方案下是否改变。

## 5. 测量、选择与标签质量

- 区分变量的理论定义、采集工具、代理指标和最终字段；记录精度、检测限、舍入、校准、批次与设备变化。
- 对重复测量、金标准子样本或已知误差范围，估计或界定测量误差；解释变量误差不能默认由普通回归吸收。
- 说明样本如何进入数据：抽样框、纳入/排除、失访、无响应、平台覆盖和人工筛选均可能造成选择偏差。
- 比较进入与未进入样本的可观测差异；选择机制无法识别时，不把样本结论无条件外推到目标总体。
- 对人工或规则生成标签，记录标注规范、标注者、复核流程、冲突率和已知标签噪声；不得把标签当作无误差真值。
- 仅当标签定义和可用时点与部署目标一致时，才可用于训练或评估；代理标签必须明确其与真实目标的偏差。

无法消除的测量误差、选择偏差或标签噪声，应进入敏感性分析或误差模型，并限制结论适用总体。

## 6. 可得性与未来信息

对每个候选特征回答：

- 它在实际预测、解释或决策时何时产生、何时可见？
- 是否由响应变量、事后信息、未来修订值或完整样本统计量直接或间接构造？
- 滚动、累计、目标编码、邻域和聚合特征是否只使用当时可获得的数据？
- 同一对象、时间段、空间单元或关联记录是否跨越训练与验证边界？
- 部署环境能否取得同口径、同频率、同延迟的数据？

任一关键特征存在无法排除的未来信息或部署不可得性时，停止建模并删除、重构或隔离该特征。

## 7. 划分与数据变换边界

- 先按时间、空间、对象、组或层级确定验证单位和划分规则，再拟合任何数据驱动变换。
- 插补、缩放、编码、离群阈值、特征选择、降维、过采样及目标相关聚合只在训练部分拟合。
- 验证和测试部分只应用训练阶段已经确定的变换，不反向参与参数选择。
- 探索性查看测试标签可能改变分析决策时，也视为信息使用并如实记录。
- 最终测试集在模型、特征和超参数冻结前保持隔离；若已被反复使用，不再称为无偏最终测试。

## 8. 清洗影响记录

每一步清洗至少记录：

| 字段 | 内容 |
|---|---|
| 规则 ID | 可唯一追踪的处理步骤 |
| 输入/输出 | 数据版本或文件 |
| 处理理由 | 数据定义、质量问题或建模需要 |
| 条件与动作 | 精确筛选、替换、转换或聚合规则 |
| 影响数量 | 处理前后行数、对象数及受影响字段数 |
| 可逆性 | 是否可回到原值；若不可逆说明原因 |
| 验证 | 小例、分布比较、连接核对或人工抽查 |

不得用“去除异常”“填补缺失”等概括性文字代替可复现规则。

## 9. 数据硬停止信号

- 来源、版本或字段定义无法确认；
- 单位、时区、时间边界或比例分母互相冲突且未消解；
- 主键粒度未知，连接后出现无法解释的行数膨胀或样本丢失；
- 缺失或异常被无记录删除，处理依据不能复现；
- 关键变量的测量定义、误差尺度或标签生成规则未知，且足以改变模型身份或评价含义；
- 样本进入机制与目标总体明显不一致，却没有校正、敏感性分析或适用范围限制；
- 标签噪声、标注冲突或代理标签偏差未审计，仍把测试标签视为无误差金标准；
- 全数据拟合了会受响应或总体分布影响的变换；
- 特征含未来、事后或验证标签信息；
- 划分破坏时间、空间、对象、组或层级依赖；
- 清洗后样本与原题要求的研究对象不再一致且未说明。

出现任一信号时，不进入正式模型比较；先修复，无法修复则标记限制并降低可回答范围。

## 10. 数据门禁输出

通过本阶段后至少形成：

- 数据来源与版本清单，含必要哈希；
- 数据字典，含对象、字段、单位、时间、空间和编码口径；
- 主键、重复、连接及行数变化审计；
- 缺失与异常诊断及处理理由；
- 测量误差、样本选择机制、标签来源与噪声审计；
- 特征可得性和未来信息检查；
- 与依赖结构一致的划分方案；
- 逐步清洗日志和分析数据版本；
- 未决问题、影响范围及门禁状态。

门禁状态只写“通过”“条件通过”或“停止”。“条件通过”必须紧邻列出条件、剩余风险及后续验证。
