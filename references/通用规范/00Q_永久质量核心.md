# 永久质量核心

本文件是数学建模任务的最小常驻门禁。它只保留任何阶段都不能丢失的红线；数据、选模、
验证执行和交付的详细检查分别在相应阶段加载。本门禁不能证明模型“绝对正确”，只能要求结论在
已列数据、来源、假设、版本与检查范围内可追踪、可复核、可推翻。

## 1. 永久红线

- 不得编造数据、样本量、时间范围、单位、来源、参数、阈值、权重、分布、随机种子、实验结果、
  显著性、置信区间、运行时间、规则或获奖信息。
- 未核验的信息标为“待核验”；合理假设必须明确写成假设，并说明依据、范围、违反后的影响及
  敏感性方案，不能伪装成已知事实。
- 竞赛规则、实时数据、行业参数、软件行为及其他动态事实在实际使用前按任务日期、对象和版本复核；
  历史来源只支持其明确适用的时期与版本。
- 区分描述、预测、模型条件下的解释和因果效应。没有识别策略及相应假设，不把相关关系写成因果。
- 任何数据变换、特征构造、插补、缩放、编码、筛选和调参都不得让验证或未来信息进入训练过程。
- 任何复杂方法必须有与目标和数据结构匹配的简单基线；复杂度增加必须对应可说明、可验证的缺陷。
- 结论强度不得超过证据：样本内拟合不等于训练外预测，预测成功不等于因果成立，局部结果不等于
  可任意外推。
- 未经证明的启发式、随机搜索或数值结果不得称为全局最优；应报告当前最好可行解、界、gap 或
  尚未证明的边界。
- 原始题面、数据、PDF、网页快照和外部代码默认只读；保留来源、版本、访问时间及必要哈希，
  不以整理或清洗覆盖原件。
- 重要结果必须能回溯到输入数据、配置、软件或求解器版本、随机种子、代码输出及报告中的对应数字。

## 2. 公式最低审查

任何进入主模型或最终报告的公式至少通过以下检查：

1. **定义**：符号、索引、集合、方向、单位和输出含义完整且前后一致；
2. **条件**：独立、平稳、可识别、凸、可微、非负等所需条件已说明并与当前问题核对；
3. **量纲**：等式两边及目标函数各项量纲相容，单位换算明确；
4. **边界**：零、常数、空集、极端值、无扰动或已知小例给出合理结果；
5. **实现一致性**：代码的索引、分母、正负号、单位、目标和约束方向与公式一致。

公式来自获奖论文、教程或代码仓库，也不能跳过上述检查。

## 3. 证据与表达

- 来源等级绑定具体主张，不把一份资料的身份扩张为其中所有公式和结论都可靠。
- 搜索摘要、博客、论坛和生成式文本只能作为线索；关键主张回到官方或原始来源核验。
- 来源冲突时先检查对象、时期、单位、口径和版本；无法消解则保留冲突、降低结论强度并做多情景。
- 数据描述使用“样本中观察到”；预测结论限定具体划分、指标和时间或空间范围；参数解释写明模型条件；
  因果和最优性术语只在相应证据充分时使用。
- 缺少必要证据时明确列出缺口与影响，不用“准确、显著、稳健、最优”等形容词补足。

## 4. 四阶段硬停止

### 数据阶段停止

数据来源、版本、口径、单位、主键、时间顺序或部署时可得性无法确认，或发现无法排除的未来信息时，
不得进入正式建模；先执行数据门禁并登记未决项。

### 选模与验证设计阶段停止

目标或估计对象、响应支持集、依赖结构、验证单位、简单基线和训练外验证方案尚未定义时，
不得用模型复杂度或单个样本内指标决定方法。

### 实现与评估阶段停止

出现公式—代码不一致、训练/调参/测试信息混用、约束或物理边界违反、结果无法复现，或复杂模型
没有在同一验证协议下与基线比较时，不得继续解释或包装结果。

### 交付阶段停止

外部动态事实未按任务日期复核、报告数字不能回溯、局限与失效条件缺失，或结论强度超过数据和
识别证据时，不得声称完成或提交。

## 5. 阶段衔接

- 进入数据读取、清洗、EDA 或特征工程时加载 [00D_数据阶段门禁.md](00D_数据阶段门禁.md)。
- 进入候选模型筛选或验证方案设计前加载 [00E_选模与验证设计门禁.md](00E_选模与验证设计门禁.md)。
- 首次正式评估结果前及输出结论前，完整使用 [11_验证敏感性与不确定性.md](../模型审查/11_验证敏感性与不确定性.md) 执行残差、敏感性、
  压力测试和不确定性检查。
- 正式论文、代码或竞赛交付再按任务路由加载相应写作、实验与提交规范。

## 6. 最小常驻检查

- [ ] 没有编造或把假设伪装成事实
- [ ] 动态事实、规则与软件行为按任务日期和版本核验
- [ ] 公式完成定义、条件、量纲、边界及实现一致性检查
- [ ] 数据和特征没有跨越验证边界或使用未来信息
- [ ] 任务类型与结论措辞一致
- [ ] 有简单基线和训练外验证设计
- [ ] 启发式或数值结果没有被误称为全局最优
- [ ] 原始资料保持只读，重要结果能够复现和追溯
