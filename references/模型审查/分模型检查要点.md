# 分模型检查要点

先检查任务、数据与验证设计，再判断模型。下表是触发清单，不是“一项不漏”的固定打分表。

| 模型或任务 | 重点证据 | 立即追问的失效信号 |
|---|---|---|
| 线性/广义线性回归 | 响应支持集、连接函数、设计矩阵、残差、依赖结构、训练外预测或推断条件 | 相关系数冒充因果；普通标准误用于强相关样本；删失当普通缺失 |
| 正则化、树、集成、神经网络 | 训练内预处理和选择、相同外层划分、结构匹配基线、重复实验、概率校准条件 | 测试集选择超参数或种子；用训练分数比较方法 |
| 时间序列 | 时间截止、预测步长、起点、季节基线、按时间外推验证 | 用未来特征；拟合残差冒充未来误差；打乱时序后声称实际预测能力 |
| 聚类 | 距离、尺度、噪声定义、簇数选择、多种子/重采样稳定性 | 二维嵌入分离被当成高维真实类别；只报告最好一次 |
| PCA/因子/降维 | 标准化位置、保留维数、载荷定义、识别性、训练内拟合 | 方差解释率直接等同预测提升；把载荷或主成分符号当因果方向 |
| 综合评价 | 指标方向、量纲、权重来源、冗余和排名敏感性 | 数据变化后沿用旧归一化；权重没有依据；单一排名被写成客观真值 |
| 线性/整数/非线性优化 | 明确目标和约束、量纲、可行性、求解状态、界与 gap、同预算基线 | 可行解写全局最优；只看目标值不查约束；不同预算直接排名 |
| 多目标/启发式优化 | 目标方向与尺度、可行非支配解、多次运行、指标与参考点定义 | 任意有限解集称真实 Pareto 前沿；只展示最漂亮的一次 |
| 微分方程/机理模型 | 初边值、量纲、守恒/不变量、参数可识别性、数值收敛、独立验证 | 求解器完成被当成机理成立；校准数据再次用于验证 |
| 随机、离散事件、多主体仿真 | 输入分布依据、预热/稳态、独立重复、蒙特卡洛误差、现实对照 | 一次轨迹代表总体；每个时间点当独立重复 |
| 图论、网络、空间模型 | 节点边含义、坐标与投影、空间/网络依赖、适用零模型 | 布局距离当物理距离；空间泄漏；度中心性自动等同因果影响 |
| 因果、实验、博弈 | 估计对象、识别假设或随机化、混杂与干扰、均衡概念、偏离检验 | SHAP/重要性替代因果识别；收益假设无来源；找到一个解就称唯一均衡 |
| 贝叶斯/潜变量模型 | 先验、似然、可识别性、推断诊断、后验预测与敏感性 | 采样诊断通过被当成模型正确；潜类别标签未经对应直接比较 |
| 文本、信号、图像 | 样本实体隔离、来源许可、标签质量、预处理边界、任务匹配指标 | 同文档/受试者/原图切片跨集合；样例挑选掩盖失败 |

## 把问题写成可核验发现

每项保留：位置 → 实际证据 → 为什么影响当前主张 → 最小修正或补证据动作 → 复核方式。缺少代码不能直接判代码错误，缺少数据不能证明结果造假；应标为证据不足及其影响。
