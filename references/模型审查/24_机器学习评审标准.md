# 机器学习评审标准

本文件用于分类、回归、排序、异常检测和表示学习。机器学习模型的可信度来自正确的数据生成假设、无泄漏验证、校准与可复现性，不来自模型名称。
树模型任务还必须读取 [31_树模型与集成学习严谨方法卡.md](../来源依据/方法依据/31_树模型与集成学习严谨方法卡.md)，其中给出 CART、Bagging、
随机森林、GBDT 和 XGBoost 的完整公式、实现边界与专项验证协议。
神经网络任务还必须读取 [32_神经网络严谨方法卡.md](../来源依据/方法依据/32_神经网络严谨方法卡.md)，其中给出前馈/反向传播、损失契约、
RNN/LSTM/GRU/CNN 的版本边界、公式—代码检查和专项验证协议。

## 1. 先写 estimand

明确要预测：

- 新时间、新地点、新主体还是同分布新样本；
- 标签在何时产生、是否延迟或含噪；
- 输出是类别、概率、连续值、排序还是风险；
- 错误代价、资源容量和决策阈值；
- 部署时输入分布与训练样本的关系。

验证划分必须模拟上述目标。随机划分只适合近似 IID 且同一实体、时间和空间邻域不会跨集合的情形。

## 2. 泄漏审计

常见泄漏：

- 先在全数据插补、缩放、筛特征、PCA、SMOTE；
- 目标编码使用验证/测试标签；
- 同一人、设备、病例或文档片段跨集合；
- 用结果发生后的字段预测结果；
- 时间序列随机划分；
- 预训练或人工标注过程接触测试标签；
- 反复查看测试集后修改模型。

所有带 `fit` 的步骤必须在训练折内部。优先用 pipeline 封装预处理、特征选择和模型。

## 3. 三层数据角色

- 训练：估计参数；
- 验证/内层 CV：选模型、超参数、阈值和特征；
- 测试/外层 CV：无偏估计最终流程。

调参和性能估计使用同一 CV 会产生选择乐观偏差。数据允许时使用嵌套交叉验证；比赛附件很小时使用重复嵌套 CV 或明确保留最终测试。

## 4. 基线与消融

分类至少比较多数类/分层随机、逻辑回归；回归至少比较均值/中位数、线性或正则回归；时间任务使用时序基线。

消融实验每次移除一个信息模块：

- 特征组；
- 复杂结构；
- 数据增强；
- 集成层；
- 校准；
- 后处理。

若复杂模块没有稳定增益，应删除或解释其其他价值。

## 5. 指标与阈值

二分类：

\[
Precision=\frac{TP}{TP+FP},\quad
Recall=\frac{TP}{TP+FN},\quad
F_1=\frac{2PR}{P+R}.
\]

分母为零时必须说明软件约定，不能静默写 0 或 1。

- ROC-AUC 衡量随机正例排在随机负例前的概率，对类别比例不敏感但可能掩盖低误报区表现；
- AUROC 的数学取值范围是 \([0,1]\)，系统性反向排序时可以低于 \(0.5\)；
  \(0.5\) 是无区分能力的基准，不是指标下界。并列得分通常按半个正确排序计入，
  使用时核对软件约定；
- PR-AUC 的基线与正例率有关，跨数据集比较要谨慎；
- “PR 曲线下面积”依赖插值约定，常用 average precision 与梯形积分结果可以不同；
  报告具体函数、版本和正类定义；
- balanced accuracy 适合类别不均衡；
- log loss、Brier score 与校准评价概率；
- macro、micro、weighted 多分类平均回答不同问题，必须注明。

阈值依据成本、容量或净收益选择，并只在训练/验证数据上确定。报告阈值变化曲线，不只给默认 0.5。

## 6. 概率校准

排序好不等于概率准。检查 reliability diagram、Brier/log loss 和分组校准。

Platt scaling、isotonic 等校准器必须用未参与基础模型拟合的数据训练。样本小时交叉验证校准；测试集只评估。

校准会随流行率和分布漂移变化。部署环境先验变化时需重新评估。

## 7. 超参数搜索

记录：

- 搜索空间与分布；
- 试验次数；
- 选择指标；
- CV 划分；
- early stopping 数据；
- 随机种子；
- 最终选择规则。

搜索越多，对验证集越容易过拟合。贝叶斯优化也不消除选择偏差。不要只报告最好一次。

## 8. 不平衡与重采样

SMOTE、上/下采样只能在训练折内执行。合成样本不能跨越群组、时间或物理边界。

优先从决策代价出发比较：

- 类别权重；
- 阈值移动；
- 重采样；
- 专用损失。

最终在原始分布的验证/测试集评估，并报告正例率。

## 9. 解释

- 线性系数依赖尺度、共线与模型设定；
- 树 impurity importance 偏好多取值/连续特征；
- permutation importance 在相关特征间分摊信息；
- PDP 可能在相关特征下查询不现实组合；
- SHAP 解释指定模型相对指定背景分布的预测分解，不是因果效应；
- 局部解释不自动推广为总体规律。

解释前先证明模型在目标数据上有足够泛化与校准。解释结果做重采样/多模型稳定性。

## 10. 分布漂移与外推

区分：

- covariate shift：\(P(X)\) 变化；
- label shift：\(P(Y)\) 变化且类条件结构近似稳定；
- concept drift：\(P(Y\mid X)\) 变化。

比较训练与部署时段的特征范围、缺失模式、类别比例、误差和校准。超出训练支持范围的样本应标记，不得仍给过度精确概率。

## 11. 公平与分组性能

当决策影响不同人群，至少报告关键分组：

- 样本量和流行率；
- sensitivity/specificity 或误差；
- 校准；
- 置信区间。

不同公平定义可能冲突。不能只选一个使模型好看的指标；说明决策场景、受保护属性的合法性和权衡。

## 12. 小样本和高维

- 先减少自由度并使用正则；
- 特征选择放在内层 CV；
- 报告学习曲线；
- 用重复/嵌套 CV 与 bootstrap 描述不确定性；
- 深度模型需强基线、多种子和预训练来源说明；
- 样本数不能只报行数，要报独立主体/事件数和有效样本量。

性能达到 1.000 或接近完美时，首先检查重复、泄漏、标签派生、错误划分和过度搜索。

### KNN 与空间索引

KNN 的距离、尺度、\(k\)、投票权重和搜索算法都要在训练内确定。KD-tree、Ball-tree
可以在合适的低维几何结构下减少查询成本，但维数升高后距离集中和树剪枝失效会使优势消失，
最坏情形不能据此宣称“高维仍高效”。高维任务应比较暴力搜索、近似近邻和先验降维，
并分别报告速度、内存与精度。

### 循环网络的边界

标准 LSTM 中门值由 sigmoid 产生，范围为 \((0,1)\)，不是 \((-1,1)\)。
候选状态和输出激活使用 \(\tanh\)，但细胞状态
\[
c_t=f_t\odot c_{t-1}+i_t\odot \widetilde c_t
\]
是加性累积量，一般不保证落在 \((-1,1)\)；有界的是
\(\tanh(c_t)\) 以及经输出门后的隐藏状态分量。LSTM 缓解而非理论上消除
梯度消失/爆炸，仍需梯度裁剪、初始化、序列长度和多种子验证。

“GRU 表达能力必然弱于 LSTM”“池化天然带来平移不变性”等说法都只能视作结构直觉；
实际优劣取决于数据、参数预算和训练过程，必须用同预算实验比较。

## 13. 聚类与无监督学习

无标签任务不能沿用监督学习“准确率”。需要：

- 多初始化和重采样稳定性；
- 距离/尺度/参数敏感性；
- 外部变量验证；
- 簇的可行动含义；
- 检查异常和缺失模式是否驱动簇。

二维嵌入仅作可视化，不能作为簇真实性证据。

## 14. 可复现性

保存：

- 原始数据哈希与划分索引；
- 代码版本、依赖和硬件；
- pipeline 与特征顺序；
- 所有种子；
- 搜索日志而非只有最优参数；
- 模型、校准器、阈值和类别映射；
- 测试集逐样本预测。

固定种子证明能复现一次；多种子分布证明结论对随机性不敏感。

## 14A. 树集成的理论表述边界

本节是评审红线摘要；推导、正增益符号、缺失/稀疏实现边界和实验矩阵见
[31_树模型与集成学习严谨方法卡.md](../来源依据/方法依据/31_树模型与集成学习严谨方法卡.md)。

若回归基学习器同方差且任意两者等相关，平均预测方差公式
\[
\operatorname{Var}(\bar f_B)=\sigma^2\left(\rho+\frac{1-\rho}{B}\right)
\]
成立，但这只是方差分解，不含偏差，也不直接推出分类错误率。

二分类错误指示独立、同分布且单个错误率 \(p<1/2\) 时，多数投票错误可用 Hoeffding
上界证明随 \(B\) 指数衰减。只有“任意两错误指示具有同一正相关系数”不足以使用普通 CLT，
也不足以推出错误率必然趋向网页给出的正态尾概率；高阶依赖结构会改变极限。
因此相关基学习器的效果以实验、margin 或适用的依赖理论评价，不套用该网页结论。

OOB 预测可作为 Bagging/随机森林内部泛化估计，但并非与整个训练流程独立：
数据仍参与其他树和超参数选择。若反复按 OOB 结果选择特征或参数，最终 OOB 误差也有选择偏差；
高风险结论仍使用外层验证或独立测试。

MAE 相比平方损失对极端误差较不敏感，但单个误差的贡献仍无上界，不能称为“不受异常值影响”。

## 15. 最低评审表

| 维度 | 必问 |
|---|---|
| 任务 | 测试集代表什么未来使用情形？ |
| 数据 | 独立样本数是多少？标签如何产生？ |
| 泄漏 | 哪些步骤会 `fit`，是否全部在折内？ |
| 基线 | 复杂模型稳定优于什么？ |
| 选择 | 调参与最终评估是否分离？ |
| 概率 | 是否校准，阈值如何确定？ |
| 稳健 | 跨时间/群组/种子是否稳定？ |
| 解释 | 是否只解释模型而没有冒充因果？ |
| 复现 | 能否从原始数据一键重建结果？ |
