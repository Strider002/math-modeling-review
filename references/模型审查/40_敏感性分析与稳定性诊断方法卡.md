# 敏感性分析与稳定性诊断方法卡

## 1. 任务边界

敏感性分析回答“哪些输入、数据、算法或结构变化会改变输出”；不确定性分析回答“这些变化共同作用时，输出有多不确定”。稳定性诊断进一步追问：模型性能、解释、排序、聚类或最终决策是否会翻转。

开始计算前必须固定四个对象：

1. **扰动对象**：参数、原始数据、预处理、随机种子、超参数、模型结构或情景；
2. **扰动规律**：区间、联合分布、重采样单位或候选结构集合；
3. **输出泛函**：预测误差、参数、排序、可行率、尾部损失、聚类一致性或决策；
4. **失败判据**：符号改变、排名翻转、越过阈值、约束失效或结论不再成立。

没有这四项的“参数上下浮动 10%”只能算未解释的扰动演示。

## 2. 先分离四类不确定来源

| 层次 | 典型扰动 | 主要问题 |
|---|---|---|
| 数据/抽样 | 重抽样、删点、测量误差、时间窗或空间单元变化 | 换一批合理数据，结论是否复现 |
| 参数/输入 | 参数分布、区间、联合情景 | 哪些输入主导输出波动 |
| 算法 | 初始化、随机种子、随机子采样、近似求解 | 同一任务重复运行是否稳定 |
| 结构/假设 | 特征集、损失、距离、链接、簇数、约束或机制 | 结论是否依赖某个可争议选择 |

四层可以组合，但应分别记录，否则无法判断波动来自数据、算法还是结构。敏感性不是因果效应：输入与输出共同变化只能说明模型内依赖，不能自动解释现实干预。

## 3. 局部敏感性：用于邻域诊断，不作全局归因

对标量输出 \(Y=f(\boldsymbol\theta)\)，局部导数为

\[
S_i(\boldsymbol\theta_0)=\left.\frac{\partial f}{\partial \theta_i}\right|_{\boldsymbol\theta_0}.
\]

无解析导数时可用中心差分：

\[
\widehat S_i(h)=\frac{f(\boldsymbol\theta_0+h\mathbf e_i)-f(\boldsymbol\theta_0-h\mathbf e_i)}{2h}.
\]

量纲不同的参数可在 \(Y\ne0\)、\(\theta_i\ne0\) 时报告局部弹性

\[
E_i=\frac{\partial Y}{\partial\theta_i}\frac{\theta_i}{Y}.
\]

实施要求：

- 同时试至少三个步长，检查排序和符号是否随 \(h\) 改变；
- 靠近约束边界时用可行的一侧差分，并明确它不是中心导数；
- 先统一单位，区分绝对变化和相对变化；
- 数值噪声大时报告差分曲线或区间，不报伪精确导数；
- 在多个有意义基点复核，不能把单一基点外推到全域。

单因素逐次改变（OAT）只探索输入空间的一维切片。对非线性、阈值、非单调和交互模型，它可能遗漏重要区域或低估联合影响，因此不能单独承担“全局重要性”结论。`source:SENS-SALTELLI-ANNONI-2010`

## 4. 全局敏感性：先定义联合输入空间

令 \(\mathbf X\sim P_X\)、\(Y=f(\mathbf X)\)。全局分析必须说明每个输入的范围/分布、相关结构、固定变量、抽样设计和输出定义。不要独立抽样本来相关的气象、价格、组分或时间变量。

在输入相互独立、\(0<\operatorname{Var}(Y)<\infty\) 的经典 Sobol 方差分解下：

\[
S_i=\frac{\operatorname{Var}_{X_i}(\mathbb E[Y\mid X_i])}{\operatorname{Var}(Y)},
\qquad
S_{T_i}=\frac{\mathbb E_{\mathbf X_{-i}}[\operatorname{Var}(Y\mid\mathbf X_{-i})]}{\operatorname{Var}(Y)}.
\]

\(S_i\)描述一阶贡献，\(S_{T_i}\)包含涉及 \(X_i\) 的交互；两者差值可提示交互，但有限样本估计误差也会造成异常值。经典分解的独立性和方差存在条件必须随公式一起写出。`source:SENS-SOBOL-2001`

输入相关时，不把经典 Sobol 指数直接解释成“独立贡献”。可选方案包括：

- 按联合分布抽样并报告条件敏感性；
- 把相关变量作为组处理；
- 使用 Shapley effects 等依赖下归因，但同时说明价值函数定义、估计误差和计算成本。`source:SENS-SHAPLEY-2016`

输出不必限于均值或方差。竞赛决策更应关注分位数、超阈概率、最坏损失、可行率、排名翻转率及建议改变率。

## 5. Bootstrap：重采样的是“独立单位”

非参数 Bootstrap 用经验分布近似未知抽样分布：重复有放回抽取与原样本同规模的数据，**每次重跑完整分析流水线**，再汇总目标统计量的经验分布。它可用于估计量、验证指标、特征入选、排序和决策稳定性；它回答的是在给定抽样机制近似下的波动，而不是证明模型最优。`source:SENS-EFRON-1979`

完整重跑至少包括：预处理拟合、特征选择、模型训练、调参规则、后处理和决策映射。把预处理或入选特征固定在全数据上再重采样，会低估流程波动。

重采样单位必须匹配依赖结构：

| 数据结构 | 典型单位/方案 |
|---|---|
| 独立个体 | 个体行，可按类别分层 |
| 同一主体重复测量 | 主体/簇级重采样 |
| 时间序列 | 移动块、圆形块等保留局部依赖的方案 |
| 空间或网络数据 | 按设计定义空间块、连通子结构或独立抽样单元 |

对相关序列逐行 i.i.d. 重采样会破坏依赖；块 Bootstrap 的块长也是假设，应做敏感性检查。`source:SENS-KUNSCH-1989`

Bootstrap 结果至少报告中位数或均值、分位数区间、区间宽度、失败运行比例，以及符号/排序/阈值/决策翻转率。经验分布不代表未观测尾部、分布漂移或结构突变；样本很小、极端事件稀少或抽样机制偏倚时，应把局限写入结论。

普通 n-out-of-n Bootstrap 并非对任意统计量都一致。样本极值、边界参数以及某些非光滑或非正则统计量需要逐项核对理论条件，不能用“无分布假设”概括为总是可靠。`source:SENS-BICKEL-FREEDMAN-1981`

## 6. 机器学习的算法稳定性

理论算法稳定性研究训练集轻微变化对学习结果和泛化误差的影响；经验上的多种子或删点波动是诊断工具，不能直接冒充某个理论稳定性定义或泛化界。`source:SENS-BOUSQUET-2002`

建议建立二维重复设计：

1. 外层改变训练样本/折；
2. 内层改变随机种子、初始化或随机子采样；
3. 对每次运行记录训练外指标、校准、关键解释量与最终决策；
4. 分别估计“换数据”和“换随机性”的波动。

只报告最好种子会形成选择偏差。模型比较应使用同一外层划分和成对差值分布；测试集保持最终独立，不参与种子、超参数或报告规则选择。

数据抽样、数据划分、初始化、增强、超参数搜索和硬件实现可以是不同随机源。应根据目标分别固定或改变，并报告分层结果；一个可复现种子只证明该次运行可重复，不证明算法对随机性稳健。`source:SENS-BOUTHILLIER-2021`

## 7. 聚类稳定性

聚类算法总能返回一个划分，但返回划分不等于数据中存在唯一、真实或有业务意义的簇。稳定性分析关注在重采样、删点、初始化、距离、标准化和簇数变化下，结构是否可复现。`source:SENS-BENHUR-2002` `source:SENS-BENDAVID-2006`

最低流程：

1. 明确样本独立单位并生成重采样/子采样数据；
2. 在每个样本内重新拟合全部预处理和聚类；
3. 用共聚类矩阵避免标签置换问题；
4. 对共有样本计算 ARI、Jaccard 或任务适配的一致性；
5. 同时检查簇大小、退化单簇/小簇、轮廓或外部解释变量；
6. 改变 \(k\)、距离和标准化，报告稳定区间而非只报最佳组合。

高稳定可能来自明显分离，也可能来自过强正则、固定预处理或退化解；低稳定可能来自连续梯度而非“算法失败”。稳定性必须与可解释性、外部有效性和下游用途一起判断。

## 8. 端到端执行清单

1. 固定主结论、输出泛函和失败判据；
2. 列出数据、参数、算法、结构四层不确定源；
3. 指定联合扰动规律和独立抽样单位；
4. 先跑量纲、边界、手算/解析小例和简单基线；
5. 局部分析用于调试与邻域方向，全局分析用于输入空间归因；
6. Bootstrap/多种子/结构替换均重跑完整流水线；
7. 输出分布、区间、失败率和结论翻转率；
8. 对最敏感区域补充情景和压力测试；
9. 检查结论是否依赖单点、单划分、单种子或单结构；
10. 把无法覆盖的尾部、漂移、依赖和识别假设写进局限。

## 9. 论文报告模板

> 我们扰动【对象】，按【区间/联合分布/重采样单位】生成【次数】次重复，并在每次重复中重新执行【预处理—选模—训练—决策】。稳定性用【指标与翻转判据】衡量。结果的【中位数/均值】为……，【分位数区间】为……，结论在……条件下保持，在……条件下失效。该分析不能覆盖【分布漂移/未观测尾部/结构误设】。

图表优先展示分布、敏感性曲线、共聚类热图、成对性能差和决策翻转矩阵；不只给一张参数权重柱状图。

## 11. 证据声明登记

| 主张 | 证据 | 使用边界 |
|---|---|---|
| OAT 不能覆盖非线性模型的多维输入空间和交互 | SENS-SALTELLI-ANNONI-2010 | 不等于 OAT 完全无用；它仍可作局部调试 |
| 经典 Sobol 一阶/总效应公式 | SENS-SOBOL-2001 | 输入独立、输出方差有限；估计器另需抽样误差评估 |
| 非参数 Bootstrap 的经验重采样思想 | SENS-EFRON-1979 | 依赖数据不能直接逐行 i.i.d. 重采样 |
| 普通 Bootstrap 存在非正则失败例 | SENS-BICKEL-FREEDMAN-1981 | 统计量的正则性与收敛条件必须逐项核验 |
| 平稳相关序列需要块式重采样 | SENS-KUNSCH-1989 | 块长、平稳性和有限样本误差另审 |
| 学习算法稳定性的理论边界 | SENS-BOUSQUET-2002 | 经验多种子波动不等于论文中的统一稳定性定理 |
| 随机算法应拆分随机来源并报告分布 | SENS-BOUTHILLIER-2021 | 固定一次种子只支持复现该次运行 |
| 聚类结构可用重采样一致性诊断 | SENS-BENHUR-2002 | 可复现不等于真实、唯一或有因果意义 |
| 依赖输入可采用 Shapley effects 归因 | SENS-SHAPLEY-2016 | 结果依赖价值函数和联合分布，计算成本较高 |

## 12. 停止与升级条件

出现以下任一情况，不得写“结果稳健”：

- 扰动范围、分布或重采样单位没有依据；
- 预处理/选模没有在重复内重做，存在信息泄漏；
- 关键结论在合理扰动下频繁翻转；
- 大量运行失败，却只汇报成功子集；
- 输入相关却按独立变量作唯一贡献解释；
- 只报告平均表现，没有区间、尾部或失败率；
- 聚类只看单次内部指标，没有重采样和结构替代；
- 使用经验 Bootstrap 外推未观测尾部或结构突变。

此时应回到数据、模型结构或决策规则层重新设计，而不是继续增加重复次数掩盖问题。
