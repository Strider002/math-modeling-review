# 常见错误与复盘索引

以下是抽象审查情形，不包含任何用户项目的参数、结果或原始产物。真实案例不能代替当前任务证据。

| 情形 | 为什么需要审查 | 应补证据 |
|---|---|---|
| 两份报告的 RMSE 排名不同 | 数据版本、划分或预处理可能不同 | 相同样本、划分和指标定义的对照 |
| 标准化后聚类数量改变 | 距离所表达的问题已经变化 | 尺度依据及多尺度稳定性分析 |
| 训练精度很高，直接声称预测准确 | 样本内拟合不等于训练外能力 | 合理独立或结构匹配的外层验证 |
| 只展示一组漂亮的图像分割结果 | 可能存在样例选择偏差 | 全测试集指标及预先定义的样例选择规则 |
| 论文中同一个结果出现多个数值 | 可能混用了版本、子群或指标口径 | 结果键、数据划分和文中位置对应表 |
| 最优目标值下降但约束未报告 | 更好的数值可能来自不可行解 | 约束违反量、求解状态与最优性边界 |
| 敏感性只扫一个参数 | 没有覆盖交互或其他不确定性 | 与主张匹配的扰动对象、联合分布和重复设计 |
| 所有误差条都叫置信区间 | 可能混用了离散程度、估计不确定性与预测区间 | 区间定义、水平、重复单位与计算方法 |

审查依据来自本包验证、机器学习评审与敏感性方法卡；本页不声明任何真实项目已经复现。
