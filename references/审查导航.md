先界定用户要查的主张与证据，不要求每次做全套审计。

| 请求 | 读取资源 |
|---|---|
| 查数据、时间/实体划分、泄漏 | [数据门禁](通用规范/00D_数据阶段门禁.md)、[选模验证门禁](通用规范/00E_选模与验证设计门禁.md) |
| 查公式、模型、基线和结论 | [分模型检查要点](模型审查/分模型检查要点.md)、[验证审计](模型审查/11_验证敏感性与不确定性.md)、[公式指标](模型审查/14_公式与指标速查.md) |
| 查分类、回归预测或学习模型 | [机器学习评审](模型审查/24_机器学习评审标准.md)，按算法读取方法依据 |
| 查敏感性、Bootstrap、多种子和聚类稳定性 | [敏感性方法卡](模型审查/40_敏感性分析与稳定性诊断方法卡.md) |

| 规划论文图表 | [模型与图表总表](论文图表/00_模型与图表总表.md)及其中对应分组 |
| 查论文表达和提交要求 | [交付检查](论文与交付/交付检查.md)、[写作与可视化](论文与交付/12_论文写作与可视化.md)、[竞赛工作流](论文与交付/13_竞赛工作流与检查清单.md) |
| 查来源 | [来源索引](来源依据/来源索引.md)；按具体主张访问合法公开原文 |
| 查逐问覆盖、绑定数字或 PDF 草稿与引用错误 | [交付审计](论文与交付/交付审计.md)；新工具为独立只读检查，不执行用户模型 |

## 方法依据

本包按需要附带若干独立方法卡，不附整个建模库；见 [方法依据索引](来源依据/方法依据/索引.md)。未附专题不构成已读证据，旧文中的扩展阅读建议不要求自动加载另一 Skill。

## 案例与结果

[常见错误索引](案例反例/常见错误与复盘索引.md)提供不含真实项目结果的审查问题。没有证据时降低结论，而不是用案例结论替代当前数据。

通用规则、案例、真实数据和合成示例必须区分。报告先列最影响结论的问题，再给具体补证据动作与可选表达建议。
