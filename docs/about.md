# 公开范围、来源与许可

## 公开范围

本项目仅分发已批准的 Skill 文本、必要来源元数据、模板和工具。未公开项目及其派生记录、原始论文附件、数据、图像和模型权重不属于本次分发范围。

网站正文、搜索索引和独立 ZIP 均从 `publication.json` 的明确清单生成。未在清单中的本地文件不会自动进入这些产物；仓库提交仍需单独审查。

## 来源与验证

每个 Skill 的来源索引、方法引用和构建信息保留在其资源目录。历史案例只在其记录的条件下有意义，不代表发布时已重新运行全部实验。

结构验证、路由验证、哈希校验和网站构建测试，不能替代数学正确性、模型效果、真实数据复现或赛事合规审查。没有发现问题不等于已经验证所有问题。
