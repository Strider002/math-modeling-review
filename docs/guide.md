# 如何使用这两个 Skill

## 选择适合当前任务的入口

| 当前任务 | 选择 |
|---|---|
| 读题、审计数据、选模型、实现与验证 | `math-modeling-library` |
| 已有方案或论文，需要检查问题和证据缺口 | `math-modeling-review` |
| 知道所用模型，想确定正文与附录的图表 | `math-modeling-review` |

两者可单独使用，不要求同时安装。科学验证仍是建模流程的一部分，不能因为有审查 Skill 就省略。

## 安装独立下载包

1. 打开相应 Skill 的“下载与使用”页面，下载 ZIP 并核对 SHA-256。
2. 解压后保留完整的 Skill 目录，不要仅复制 `SKILL.md`。
3. Codex 的项目级安装可放在 `.agents/skills/` 下，目录名保持 Skill 名称。已有同名 Skill 时先比较版本，不直接覆盖。
4. 在对话中输入 `$math-modeling-library` 或 `$math-modeling-review` 并说明任务。其他工具的配置以其官方文档为准。

位置及调用方式依据 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)；具体客户端行为可能更新。

## 示例请求

建模：

```text
$math-modeling-library
请根据我提供的题面和数据说明，先拆解问题、识别数据风险，
提出简单基线与验证方案。先分析，不运行训练代码。
```

审查：

```text
$math-modeling-review
只读审查我提供的模型说明和结果表。
按“阻断结论、可信度缺口、可选改进”列出问题，并说明依据。
```

图表规划：

```text
$math-modeling-review
我使用回归和多目标优化。请按实际论文主张，列出候选图表、
所需字段、适用条件、正文或附录位置；缺结果时明确指出，不编造曲线。
```

## 网站与 Skill 有什么区别

网站用于阅读、导航、检索和下载，不会在网页上运行模型，也不提供 AI 在线问答。Skill 是提供给支持该格式的 Agent 的任务指导与资源，不是独立的模型训练软件。

搜索默认仅搜索当前 Skill；切换另一 Skill 后可搜索其内容。两站顶部与侧栏的公共导航相同。

PowerShell 工具要求 PowerShell 7。没有对应运行环境时可以阅读资源，但不能声称脚本已经执行。

## 使用边界

先检查当届赛事的 AI、匿名、格式和提交规定。文档中的规则快照不代替最新官方规则。重要公式与结论应由团队核对；本项目不承诺获奖或绝对正确。
